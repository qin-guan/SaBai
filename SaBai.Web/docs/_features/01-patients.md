## Introduction

The Patients page displays all the basic information of the patients, in ascending order of their registration. The fields displayed are:
- ID and photo
- Name
- Basic info (Gender, age, contact number)
- Status Flags (POOR, Sabai, BS2 card)

## Deleting a patient

Admins see a **Delete Patient** button on the patient page. Deleting a patient is
permanent: it removes their visits (with vitals, vision and dental records),
consults (with diagnoses, referrals and medication orders), uploaded files,
profile photo and enrolled faces. Stock already dispensed for approved orders is
not returned to stock. To confirm, type the patient's code (for example `PC0012`).
